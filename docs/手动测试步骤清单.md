# 交易客户端手动测试步骤清单

> **前置条件**：
> ```bash
> # 1. 启动后端（保持运行）
> python -m uvicorn backend_fastapi.main:app --port 8000
> # 2. 启动前端（新终端）
> npm run dev
> ```
> 浏览器访问 `http://localhost:5173`

测试账号：`admin` / 密码 `123456`

---

## 功能1：登录（📷 截图1）

| 步 | 操作 | 截图点 |
|----|------|--------|
| 1 | 打开 `http://localhost:5173` | 📷 登录页全貌 |
| 2 | 输入 admin / 123456，点"进入工作台" | 📷 登录后的 Dashboard |

## 功能4-5：买入与卖出（📷 截图6-7）

| 步 | 操作 | 截图点 |
|----|------|--------|
| 1 | 点"交易"菜单，选"买入" | |
| 2 | 填代码 600001，价格 149，数量 100 | 📷 买入表单（填好状态） |
| 3 | 点"预览"→点"提交委托" | |
| 4 | 切到"卖出"，填代码 600001，价格 160，数量 100 | 📷 卖出表单 |
